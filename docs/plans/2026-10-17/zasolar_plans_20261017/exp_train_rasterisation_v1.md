# 实验设计：训练标签像素中心栅格化 + 收窄忽略带（v1，2026-10-17，只是设计，未跑）

批准依据：葉 2026-10-17 批准 round-1 建议（OPEN_QUESTIONS_round1.md 第 5 题）。GPU 未批，开跑前需葉单独批准。

## 假设
H1：训练 mask 从 all_touched 改为像素中心，可降低小板面积高估（all_touched 对 2 m² 板约 +15%，PLAN §5 Q2），面积比更接近 1，且 object F1 不降。
H2：忽略带从 ±0.3 m（6 px）收窄到 ±0.1 m（2 px）或取消，可提高边界 F（BF@0.25/0.5 m），代价是 pixel IoU 可能小幅下降。

## 设计（两轮，分开测，不同时改两个变量）
| 臂 | 栅格化 | 忽略带 | 说明 |
|---|---|---|---|
| R0 基线 | all_touched | ±6 px | 按现有 v2d2 配方重训（同 seed），不复用旧 checkpoint 数字 |
| R1 | 像素中心 | ±6 px | 只改栅格化 |
| R2 | 像素中心 | ±2 px | 在 R1 基础上收窄忽略带 |
| R3（可选）| 像素中心 | 无 | 仅当 R2 优于 R1 时跑 |
所有臂：同 v2d2 数据与划分（若 exp_split_dedupe 先结论，则统一用去重后的划分）、同超参、同步数、同阈值选择规则（val 上选 prob_cfg）。mask 用 zaeval-2 两值编码（254 格外区，255 边缘带）。

## 数据
- 训练/验证：v2d2 grids（manifest v3.2 train/val），重新生成 mask 到新目录（原件不动），md5 记录。
- 评估：val（全 1768 tile）+ Li 测试集 group A（规则见 TEST_RULES_frozen_20261017.md，冻结后才看分）。

## 指标（并排报告，不锁单一主指标；全部 zaeval-2）
object P/R/F1 @IoU 0.3/0.5/0.7；小板召回按面积档 <4 / 4–10 / ≥10 m²（含 n 与 Wilson CI）；BF@0.25/0.5 m（主），0.3/1.0 m（诊断）；pixel IoU；面积比（pred/GT，按档）；按 label_source 分组。评估端统一用像素中心 GT，legacy 列仅作对照。

## GPU 预算（T = b2 一次完整训练 3.2 GPU-h，实测）
- 每臂 1 seed：R0–R2 = 3T ≈ 9.6 GPU-h；评估推理约 +0.5 GPU-h/臂（估计）→ 约 11 GPU-h。
- 若差异落在噪声内，补 2 个 seed：再 +6T ≈ 19 GPU-h。R3 +1T。上限 33 GPU-h（估计）。

## 停止条件
- 任一臂训练 loss 发散或 val F1 比 R0 低 >0.02 于中途检查点 → 停该臂。
- R1 相对 R0：面积比改善 <0.02 且 F1 下降 → 不再跑 R2/R3，结论"不改栅格化"。
- 单 seed 差异 < 已测 seed 噪声（若尚未测，先测 R0 第二个 seed）→ 不下结论，补 seed 或停。
- 超出葉批准的 GPU 上限即停。

## 支撑的决定
下一版训练标签（v2e）是否改用像素中心栅格化、忽略带宽度取多少；以及普查面积估计是否需要对旧模型做面积偏差校正。
